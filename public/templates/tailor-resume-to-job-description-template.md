# JD-to-Resume Tailoring Worksheet
### A free one-pager from AdaptiveResume

Fifteen focused minutes per posting. Print one per application.

## Step 1 — Grade the job description
Read the posting once, then fill in:

**Must-haves** (repeated terms, first three bullets, anything with a number or named credential/system, everything under "Requirements"):
1. ____________________
2. ____________________
3. ____________________
4. ____________________
5. ____________________

**Nice-to-haves** (wish-list items, "familiarity with," culture adjectives):
- ____________________
- ____________________

## Step 2 — Match honestly
For each must-have:

| Their term (JD's exact words) | Have you genuinely done it? | Your resume's current wording |
|-------------------------------|------------------------------|-------------------------------|
| | Yes / No / Close | |
| | Yes / No / Close | |
| | Yes / No / Close | |
| | Yes / No / Close | |
| | Yes / No / Close | |

- **Yes** → use their exact term in your bullet (keep the industry-standard term too).
- **Close** → describe your real closest experience; do NOT adopt their term.
- **No** → leave it visibly absent. A missing skill is survivable; a discovered stretch is not.

## Step 3 — Reorder
- [ ] In each job: bullets that hit this JD's must-haves moved to the top
- [ ] Skills section: must-have skills first, not alphabetical
- [ ] Summary: names your 2–3 strongest real matches to this posting

## Step 4 — The three lines you never cross
1. No term for something you haven't done — the keyword gets you found, the human checks it's true.
2. No changed job titles — titles are checkable facts.
3. If you'd squint to call your work by their term, don't.

## The gut check
If honest tailoring can't produce a decent match against the must-have list, spend the fifteen minutes on the next posting instead.
